# 規則排除條件

每條通知規則由一個主要條件與零到多個排除條件組成。

## 比對方式

主要條件維持既有兩種：

- 標題包含關鍵字。
- 作者帳號完全符合。

排除條件固定套用在文章標題：

- 標題不包含指定關鍵字。
- 一條規則最多可加入 10 個排除關鍵字。
- 只要文章標題包含任一排除關鍵字，整條規則就不成立。
- 英文大小寫設定會同時套用到主要條件與排除條件。

## 範例

MacShop 的 Mac mini 販賣文章：

- 看板：`MacShop`
- 主要條件：標題包含 `Mac mini`
- 排除條件：標題不包含 `徵求`
- 排除條件：標題不包含 `收購`

因此 `[販售] M4 Mac mini` 會命中，但 `[徵求] M4 Mac mini` 不會命中。

既有規則在資料庫升級後會自動取得空的排除條件清單，不需要手動調整。
